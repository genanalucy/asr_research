# 降低壮语 CER 到 3% 的调研与执行路线

日期：2026-10-14。用户已决定放弃“跨说话人效用驱动的 LoRA 参数分配”作为主线，目标改为尽可能提高壮语原文 ASR 准确率。本文把 3% 作为挑战目标，不承诺必达。当前三条 Whisper-medium 全量微调仍在运行，已取得的完整开发集结果不是最终结果，也不是测试成绩。

## 先判断 3% 的难度

当前完整开发集参考字符数为 178,266。最佳已观测 CER 为 7.57%，对应 13,494 个字符编辑错误。CER 3%约等于5,348个编辑错误，需要额外消除约8,146个错误，减少约60%。这不是再训练几个epoch或微调一个学习率的小改进，而是需要同时处理错误来源。

当前三条medium的完整dev最佳值：

| LR | 最佳step | CER | whitespace-token WER | 状态 |
|---:|---:|---:|---:|---|
| 1e-5 | 10,464 | 7.57% | 36.87% | 仍训练 |
| 3e-5 | 6,976 | 8.54% | 38.94% | 仍训练 |
| 7e-5 | 10,464 | 9.72% | 41.11% | 仍训练 |

3%是否可达，必须先知道13,494个错误由什么组成。若其中大量是文本规范、空格、大小写、标点或标签冲突，清理后会有明显下降；若主要是未见说话人/声学混淆，必须改训练数据或表示；若主要是解码和语言约束，LM/beam可能有收益。不能在没有错误归因前承诺一个方法。

## 文献调研得到的可用路线

### 1. 训练集文字 n-gram + 约束 beam 重打分：最快的无训练增益候选

Whisper-LM（arXiv 2503.23542）在 Whisper 解码分数中加入外部 LM：

`Q(c|x)=log P_acoustic(c|x)+α log P_LM(c)+β word_count(c)`

其方法在词边界融合5-gram KenLM，并在验证集调 α、β；论文报告低资源设置中统计LM可带来较大相对改进，但其语言、数据和评分不能外推到壮语。Hawaiian 论文（arXiv 2404.03073）在约150万词独立夏威夷语文本上做LM重打分，摘要报告小但显著的WER改善。Iu Mien论文（arXiv 2407.13292）用4-gram KenLM + WFST beam 32；其约9.7小时数据中，Whistle subword WER从3.30降到2.95，phoneme路线从2.95降到2.71。

对当前项目的做法：

1. 只用train文本训练字符/子词5-gram；不使用dev/test参考文本。
2. 先让当前medium best checkpoint生成固定n-best或beam候选。
3. 在train内部或dev的独立调参子集上调 LM 权重、长度项和beam；正式dev只用于确认，不反复根据test调参。
4. 比较greedy、Whisper beam、n-gram重打分；同时报告CER和token-WER。
5. 检查候选是否把未说内容补进去；对长句、重复、插入错误分层。

预期：对token-WER和插入/重复错误更可能有效，对CER的收益取决于壮语文字上下文是否强、训练文本规模和transcript重复度。它不太可能单独把7.5%降到3%，但这是成本最低、应优先验证的路线。

### 2. 正字法/标签审计与统一：可能带来最大“测量和真实训练”收益

Yolóxochitl Mixtec研究（EACL 2021）同时比较 underlying/surface orthography，并强调形态边界、声调和代码切换会影响CER/WER。其约92小时、34说话人Conformer结果约7.7 CER、16 WER；10/20/50小时曲线分别约39.1/26.2/18.0 WER，说明数据规模、文本层级和评测规范共同决定结果。

本项目必须先做错误审计：

- 同一说话内容是否出现多个壮语文本版本；
- 大小写、标点、空格、连字符和调号是否统一；
- 是否存在文本冲突、音频重复和切分边界错误；
- Whisper tokenizer是否把常见壮文组合切成过多碎片；
- CER错误是否集中在少数高频字符、低频字符或某些说话人；
- train/dev共享prompt时，错误究竟是声学还是文本覆盖差异。

必须保存两套分数：

- **原始正字法分数**：主结果，不为追分临时修改；
- **预注册规范化分数**：规则必须在最终评测前固定，并报告具体规则。

如果7.57%的错误中有大量规范不一致，统一规范可能显著改善训练和评估；这属于数据/评测修复，不能包装成新模型方法。若人工复核发现标签本身不确定，保留“不确定”类别，不强行改成模型预测。

### 3. 更强主干或不同声学表示：准确率主线

当前medium已经达到约7.6 CER，但尚未完成8epoch。先让三条medium完成，选择完整dev best。之后可比较：

- Whisper-large-v3 full FT；
- W2v-BERT 2.0 + CTC头；
- XLS-R-300M CTC重新用完整数据、合理训练预算；
- 有条件时Whistle/音素预训练路线。

W2v-BERT官方模型卡显示它是600M Conformer encoder、使用filterbank、需另接ASR头；不能直接替换当前XLS-R脚本。Iu Mien论文显示弱监督音素多语言预训练和phoneme目标可能改善低资源声学识别，但其数据是约9.7小时单说话人，不能直接预测武鸣壮语。

大模型可能降低声学错误，但不保证达到3%。如果当前瓶颈是标签、文本规范或domain mismatch，单纯增加参数可能收益很小。large-v3应作为一次强对照，不要在未完成medium分析前启动巨大模型矩阵。

### 4. 目标语继续预训练 + 监督微调：利用现有音频的声学适配

ATDS论文（arXiv 2402.02302）在少标签条件下做target/donor continued pretraining，再监督微调；目标语10小时、donor60小时的CPT需要约4×A100 15小时一轮。它说明目标/供体声学表示适配可能有效，但原文目标标签远少于本项目107小时，收益不能直接外推。

对本项目可做轻量版本：

1. 只用train音频做XLS-R/W2v-BERT自监督CPT；不使用test音频；
2. CPT后使用同一107小时真实壮语转写监督微调；
3. 与等更新预算的直接监督微调比较；
4. 先只做一个短CPT pilot，确认dev是否改善再扩大。

它更可能改善声学表示和说话人/录音域鲁棒性，无法保证改善正字法或解码错误。Whisper-medium的decoder不适合直接套wav2vec式CPT，因此优先用于SSL encoder路线。

### 5. 域匹配和两阶段训练：若数据含朗读/圣经/来源差异，优先于盲目混合

Faithful Transcription（IJCNLP-AACL 2025）在多种濒危语言中发现：Bible朗读数据通常比非Bible数据多5–10倍，但直接拼接Bible和自然语音可能使非Bible WER变差；先用Bible继续训练，再用目标非Bible数据微调，是更稳定的策略。词汇overlap与WER显著相关（其图5报告Pearson r=-0.711）。

本项目应检查壮语train的来源、录音风格、prompt重复度和说话人/设备。如果train内部有明显域：

- 做domain标签和逐域dev CER；
- 先在大朗读域做表示适配，再用目标域转写微调；
- 比较直接混合、domain-balanced采样、两阶段训练；
- 不把域效应称语言或说话人效应。

这是达到3%更现实的路线之一，因为它直接针对train/dev不匹配，而不是只扩大模型容量。

### 6. 音素/音节/声调辅助目标：条件性路线

Iu Mien论文显示phoneme目标可能优于subword；SITA（arXiv 2601.09050）则用跨说话人对比、同词异调排斥、音调分类和ASR蒸馏，试图同时保持说话人不变和声调敏感。但SITA报告的主要任务是Hmong词+调的特殊数据，且其ASR WER/CER结果不能外推到武鸣壮语。

只有在壮语可靠的音节/声调/G2P标注可用时才做：

- encoder加辅助音节/音素/声调头；
- CTC/attention联合训练；
- 训练后报告声母、韵母、声调和整字错误；
- 没有可靠音系映射时不伪造TER/FER。

这个路线可能改善声学混淆，但实现和查新成本高，不能作为第一步。

## 推荐的实执行顺序

### 阶段A：错误归因（现有训练结束后立即做）

对三个medium的完整dev best checkpoint统一生成匿名错误统计：

1. 按句、按说话人、按音频时长、按文本长度分层；
2. 插入/删除/替换分别统计；
3. 字符频次、token频次、OOV和subword长度分层；
4. 共享prompt/novel prompt分层；
5. 音频来源、设备、域和录音风格分层；
6. 人工抽样检查标签一致性和正字法差异。

决策门：

- 若规范/标签错误占大头：先修数据和评分，再重训；
- 若插入、重复和语言序列错误占大头：先LM/n-best重打分；
- 若不同说话人和域差距占大头：做domain-balanced、CPT或更强SSL encoder；
- 若字符/音节声学混淆占大头：做音素/音节辅助任务或更强声学主干。

### 阶段B：低成本收益

1. 训练集文本5-gram + beam/n-best重打分；
2. 固定候选、预先调参、完整dev确认；
3. 对原始评分和预注册规范化评分分别报告；
4. 若CER改善小但WER明显改善，作为辅助结果，不宣称达到3%。

### 阶段C：针对性重训

根据错误归因只选一条：

- 标签/正字法：清理后重训medium best LR；
- 域差异：domain-balanced或两阶段适配；
- 声学错误：large-v3或SSL encoder/CPT；
- 音系错误：有可靠标注才做phoneme/tone auxiliary。

每条只做一个主改动，并保留原medium强基线。

### 阶段D：冻结与最终测试

- 在train和dev冻结评分规则、模型、LM、beam、checkpoint和所有阈值；
- 仅此后使用test一次；
- 同时报告CER、原始token-WER、规范化token-WER、逐说话人指标；
- 做experiment-audit，确认没有test泄漏、参考文本泄漏或分数归一化问题。

## 预期效果与结论边界

| 路线 | 适合解决 | 对CER<3%的现实判断 |
|---|---|---|
| 文本LM/n-best | 插入、重复、上下文/词序 | 低成本，可能改善WER，单独到3%不太可能 |
| 标签/正字法清理 | 冲突、规范差异、不可学习目标 | 若错误占大头，最可能有显著收益 |
| large-v3/强SSL | 声学和说话人泛化 | 有机会继续降，但不能保证 |
| CPT/两阶段域适配 | 域偏置、朗读/自然语音差异 | 若存在域差异，有潜力；需要严格对照 |
| 音素/声调辅助 | 声学细粒度混淆 | 依赖可靠音系标注，成本高 |
| SITA式speaker/tone表示 | 音调和说话人纠缠 | 近邻较新，不能直接移植，先做诊断 |

如果错误分析显示多个问题共同存在，3%可能需要组合：标签修订 → domain-balanced/两阶段训练 → LM重打分 → 更强主干。每次组合前先记录单项收益，否则无法知道哪一步有效。

最稳妥的论文主张应是：**通过错误归因驱动的数据、域、解码和声学适配，逐步建立武鸣壮语ASR的准确率上限；3%是挑战目标，最终是否达到由冻结测试结果决定。**不把“尝试过很多方法”写成创新，重点报告每条路线对错误类型的实际影响。
