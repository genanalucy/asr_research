# 武鸣壮语 ASR：迁移学习与快速成果路线

更新：2026-10-14（北京时间）。用途：根据现有数据、试跑与近邻文献，选择下一轮研究路线。本文是定向比较调研，不是穷尽检索或首创证明；时间为排期估算，不是服务器实测承诺。

## 建议先做什么

**先用完整壮语训练集建立强模型，然后把主问题收敛到“声学编码器与文字解码器需要怎样适配”；教师—学生蒸馏作为第二候选。** 不把普通 LoRA、自动调参或换大模型单独包装成新算法。

已有 Whisper-small / XLS-R-300M 微调本来就是迁移学习。现在需要从 5h 工程试跑升级到完整训练，而不是从头重新训练基础模型。

- 壮语保守候选池：120.77h、26 个真实说话人前缀；当前固定划分为训练 107.407h / 55,805 条 / 22 人，开发 7.844h / 2 人，测试 5.521h / 2 人。
- 瑶语候选约 37.83h；语言变体、实际说话人身份和章节来源仍需核验。不能把 19 个工作 ID 当作 19 个独立说话人。
- 用户至少 4 张 L20 的预算适合并行微调、有限搜索、种子复验；实际可用 GPU 每次启动前检查。
- 5h 试跑的共同开发监控集只有 128 条：Whisper-small CER 15.78%，XLS-R-300M 17.83%。不是全开发集成绩、测试成绩或充分收敛的结论。
- 107h 标签对目标语言很有价值，相比基础模型的预训练规模仍有限；它支持较强的监督适配，不等于已有数万小时无标签语料。

## 八个可选方向

“首批结果”指能形成一个可信开发集对照，不包含投稿、完整消融或全部种子。需要改变管线的路线预计更慢，下载和共享服务器排队另计。

| 方向 | 具体做法及数据用途 | 首批结果估计 | 可形成的研究贡献与近邻风险 | 建议 |
|---|---|---|---|---|
| 1. 强主干 + 全量微调 + 有界调参 | Whisper-medium 为首个强主干，必要时 large-v3；XLS-R 作为异构对照，W2v-BERT 2.0 后补。完整 107h 训练；搜索 LR、有效 batch、warmup、正则 | 1–3 天 | 快速形成实用强基线；单纯成绩提升或 Optuna 搜索通常是工程贡献。Optuna-LoRA 已有直接先例 [R3] | **必须做，作为共同底座** |
| 2. 编码器/解码器分层适配 | 比较统一 LR、encoder/decoder 不同 LR、渐进解冻；研究新语言声学与正字法适配是否需要不同更新强度 | 2–4 天 | 适合已有大量配对标签；贡献可能是受控实证规律与稳定配方。分层 LR/冻结本身不是新发明；需证明收益跨种子和数据规模保持 | **优先主线** |
| 3. 参数预算下的 LoRA 配置 | 同主干比较全量 FT、均匀 LoRA、encoder/decoder 不同预算；控制可训练参数量及搜索预算 | 2–4 天 | 新语言 LoRA、供体 LoRA 初始化、adaptive rank 已有先例 [R1,R2,R4,R10,R11]。只有真实区别及公平对照后才讨论方法贡献 | 可作为方向 2 的一组实验，不单独许诺首创 |
| 4. 目标语自监督继续预训练（CPT）→监督微调 | 在 XLS-R 等 SSL 编码器上用训练音频做自监督 CPT，再用原有真转写训练；可比较 target-only 和 target+Yao | 3–6 天 | 能用算力加强目标语声学表示；但原近邻多在极少标签条件 [R5]，107h 标签时收益未知。需直接 FT 和等额外训练预算对照 | 第二梯队；比直接 FT 更慢 |
| 5. 壮语/瑶语顺序迁移与联合训练 | 分别比较目标语直接 FT、供体→目标 FT、平衡联合训练、语言独立 adapter；统一输出与任务提示策略 | 3–6 天，身份核验另计 | 可研究负迁移及采样比例。不能预设两语亲缘；供体收益不保证 [R6]。壮→瑶和瑶→壮是不同问题，不能混报 | 瑶语核验后作为第二语言验证 |
| 6. 已适配大教师→小学生蒸馏 | 先完整数据适配 medium/large 教师，再训练 small 学生；真实标签 CE + 教师软分布，比较无 KD/标准 KD/候选可靠性处理 | 3–5 天起；完整证据约 1–2 周 | 可同时报告 CER、速度、显存。标准 KD 和参考 WER 过滤已见 Distil-Whisper [R7]；需找到真实教师错误问题和不同机制 | **方法路线备选，投入略大** |
| 7. 训练文字 LM / 声学约束重打分 | 用 train 文本训练 n-gram 或轻量 LM，比较 greedy、beam、LM rescoring；Whisper 可另做 n-best reranking | 1–2 天 | 可能快速改善正字法/词序；训练文本有限且重复，收益需实测。LM 集成已有先例 [R8,R9]，普通重打分不是首创 | 适合作为快收益模块 |
| 8. 辅助 CTC 或语言学多任务 | Whisper encoder 加 CTC 辅助头，或者在可靠正字法—音系解析后加音节/声调任务；全数据共同监督 | 辅助 CTC 3–5 天；音系方案需额外核验 | 联合 CTC/attention 早已有先例；声调任务也拥挤。当前没有可靠调类/音系映射，不能凭删字母创造 TER | 不作为当前最快主线 |

如果没有额外未标注语音，普通 self-training 不是第一优先：当前这批数据已经有真实转写。可以研究教师软监督，但不能把已有标签换成机器文本后称为新增数据。

另一个条件性方向是 **tokenizer / 正字法适配**：先量化壮文被切成多少 token、长序列截断和低频字符组合错误，再决定是否增加词表项或调整嵌入。预计 3–7 天起，实现会影响输出层、checkpoint 与蒸馏对齐；新 language code/soft prompt 已有先例 [R1]。在确认 tokenizer 是瓶颈之前，不优先改词表。

## 首选主线：分层适配与全量 FT / PEFT 的真实差距

暂定研究问题：

> 在拥有约百小时配对标注、但基础模型未显式支持的武鸣壮语上，统一微调与声学—文字分层适配如何影响识别误差？参数受限适配与全量更新的差距是否随训练规模和模型规模变化？

工作标题可用：**《百小时武鸣壮语语音识别中的声学—文字分层迁移适配研究》**。这是工作题名，不能以题名证明创新。

### 可证伪假设

- H1：encoder 和 decoder 使用同一更新强度不一定是最佳配置；开发集收益必须在完整训练、同等调参预算下复现。
- H2：在 107h 监督条件下，参数高效适配与全量更新的差距可能不同于 5–10h 条件；方向和大小都由实验决定。
- H3：小模型上有效的层配置不一定能迁移到更大主干，因此至少对 small/medium 做关键配置复核。

H1 的“分层 LR”机制本身是已有技术，H2/H3 是经验问题。目前没有证据支持“此前从未研究过”；查新应进一步覆盖 layer-wise learning rate、partial fine-tuning、gradual unfreezing、encoder/decoder adapter allocation 等近邻。若只得到普通调参增益，论文应定位为目标语言的实证适配研究，而不是新网络结构论文。

### 最小对照矩阵

先以 Whisper 为主，避免第一轮同时重写三个模型族。

| 配置 | 目的 | 公平性要求 |
|---|---|---|
| A. 全量 FT + 统一 LR | 强基线 | 对它也做合理 LR 搜索，不能故意用差配置 |
| B. 均匀 LoRA | PEFT 基线 | 明确作用模块、rank、alpha、dropout 与参数数目 |
| C. 全量 FT + encoder/decoder 分组 LR | 隔离更新强度作用 | 同 A 数据、解码、batch、停止规则；两组 LR 预先列出候选 |
| D. 固定总参数预算的分组 LoRA | 隔离参数位置作用 | 与 B 可训练参数量尽量一致；不同矩阵宽度下核算实际参数，不能只比较 rank |
| E. 渐进解冻 | 候选补充 | C/D 没有优势时再决定是否投入，不与所有其他改动一起叠加 |

主要分析先比较 A/B/C/D；先分别检验 LR 分组与参数位置，避免把两者混在一起无法归因。各方法获相同数量的搜索试验与明确 GPU 时上限，最终报告实际搜索成本和训练成本。

如果 D 表现出收益并准备主张“参数分配策略更好”，必须再加入至少一个现有强参数分配基线（例如 AdaLoRA 或 S2-LoRA [R11]），普通 LoRA 一个对照不足。最新 LoRA-to-LoRA 正式论文 [R10] 已覆盖 40–100h 目标语言条件，因此“用了百小时数据做供体迁移”也不构成独立的新颖性证据。

- 20h 固定 train 子集仅用于筛掉坏超参数；最终关键配置全部在 107h 训练集训练，不丢弃剩余样本。
- 用 20h / 50h / 107h 三个嵌套规模点检验观察是否只在小样本成立。小规模只保留 A/B/胜出候选，避免完整笛卡尔积。
- 107h 的 A/B/胜出候选优先完成 3 个 seed；small 上做这些关键配置复核。
- 不预设某方法必须获胜。如果 C/D 无稳定收益，应明确保留负结果并转向错误分析或蒸馏路线。

## 第二候选：面向目标语言的教师—学生蒸馏

研究问题：在已有真实转写的百小时目标语言数据上，一个已适配教师能否提高小学生的准确率，并达到更好的准确率—推理成本折中？教师错误会否在学生上被放大？

优先用 **Whisper-medium → Whisper-small** 验证，先核对实际 tokenizer、词表、special tokens 和输入特征一致性。large-v3 可作为独立强基线；它与 small 的 mel 维度/词表区别使逐 token 蒸馏不能无检查直接套用。

1. 教师先只在 train 上微调，以 dev 选择 checkpoint；不能假定原模型会壮语。
2. 相同 small 学生：真实标签监督 / 标签+标准 KD / 标签+候选可靠性 KD。
3. 为了低复杂度，先在真实参考前缀下比较 teacher-forced token 分布；如果使用生成伪标签，另说明序列对齐与筛选方法。
4. 所有学生保留真实标签硬监督。可靠性规则若使用参考误差，只能使用 train 参考；dev 用于固定阈值，test 不参与。
5. 可靠性/置信度加权和过滤也有大量先例。只有找到具体失效、与标准 KD 和既有过滤规则公平比较，才能提出候选改进；现阶段不是已查新通过的方法。
6. 报告 CER、token WER、参数量、峰值显存、RTF；同设备、batch、beam、precision，预热后计时。教师生产成本单列，不用学生推理优势掩盖训练开销。

如果教师没有稳定优于学生、标准 KD 未改善，或所谓机制只在一个 seed 有效，不推进“蒸馏有效”的论文主张。

## 48–72 小时的首轮排期

以下从下一轮启动时起计，不是当前已有新训练在运行。下载、实现和算力排队可延长。

| 阶段 | 内容 | 估计墙钟时间 | 并行方式 / 输出 |
|---|---|---:|---|
| 0 | 冻结 train/dev 清单；检查 medium 模型、输入长度、标签截断、缓存与 GPU；先跑百步测吞吐 | 2–6h | CPU 准备和模型下载可并行；输出真实 steps/s、显存与全轮估算 |
| 1 | small 全数据基线；medium FT/LoRA 在 20h 上有限搜索（初轮 4–8 配置，预设候选） | 6–18h | 有 4 卡时 1 卡全量基线、2 卡筛选、1 卡评估/备选；仅有 3 卡时延后备选 |
| 2 | medium 全量 FT、全量 LoRA、一个胜出分层配置 | 12–36h | 三条独立单卡进程并行；先测显存，必要时梯度累积/检查点 |
| 3 | 完整 dev 评测、按两位 dev 说话人分别报告；train 内样本错误诊断；决定是否继续分层主线 | 3–8h | 评测尽量在训练不占用的 GPU；生成第一张真实比较表 |
| 4 | 3 seeds、关键 20/50/107h 曲线、small 复核或蒸馏一轮 | 再 3–7 天起 | 根据阶段 3 证据只扩展一条主线 |

目标是 **1–3 天先获得较强全数据开发集对照；约 1–2 周形成较完整的论文证据**。这不是保证改进幅度、完成投稿或录用。

已有 small 单卡试跑约 23 分钟 / 1500 steps，effective batch 16。机械外推至 55,805 条约 3488 steps/epoch，small 约 0.87h/epoch；完整 5–15 epoch 约 4.4–13h。该估算忽略音频长度分布、评估与 IO，仅作为启动前量级参考。medium/large、LoRA、CTC 的速度不能按参数量或原试跑时长线性保证；先测 100–300 steps 再更新排期。多卡独立搜索也不等于一条训练自动获得 4 倍加速。

## 评测和写作边界

- 固定 speaker-disjoint 划分与音频去重规则；共享文本允许存在，但报告内容重合，不能宣称已完全隔离录音域或朗读内容。
- 选模型使用完整 dev 或预先固定 monitor；论文主表用完整 dev。test 在配方冻结后按预定矩阵评测，不用于训练、CPT、LM 或阈值搜索。
- 保持同一文本规范与评分实现。当前 CER 排除空白，NFC+空白折叠外保留大小写、标点、数字；WER 是空格 token，不能自动解释为语言学词错误率。
- 正字法规范化、解码、LM、层更新必须分别做消融；不能通过删除声调信息/标点制造方法收益。
- 当前 dev/test 各仅两名说话人。句级 bootstrap 可描述这批话语的不确定性，不能当作对整个武鸣说话人群体的强泛化证据。报告逐人指标，并对关键配置考虑 train 内说话人轮换留出的稳健性检查。
- 3 seeds 反映优化随机性，不等于增加了独立测试说话人数。每条配置记录模型 revision、split hash、训练预算、batch、seed、参数数目与失败记录。
- 论文应依次讲清：已有问题与近邻 → 数据与过滤 → 强迁移基线 → 候选适配机制 → 公平对照与误差分析 → 局限。研究发现留待数据决定。
- 若仅目标语基线表现良好，可写扎实的应用/实证论文；如果要投更强调方法创新的会议，需要继续专项查新、明确与近邻的差异，最好有可信第二语言或外部数据验证。
