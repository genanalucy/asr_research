# 壮语/瑶语 ASR 项目执行计划：时间、依赖与并行

更新时间：2026-10-13。时间均为当前服务器条件下的估计区间，不是已经发生的实验结果。训练时间必须用第一轮 5 小时基线的真实吞吐重新校准。

## 总体安排

核心路径是：数据异常复核 → 说话人/来源映射 → 固定 split → 极小集过拟合 → 5h 双基线 → 核心实验 → 结果分析 → 论文定稿。文献专项检索、全文下载、环境盘点和论文方法节可以并行；split 冻结前不能跑正式测试，指标未通过单测前不能比较模型，5 小时吞吐未测量前不承诺完整矩阵的 wall-clock。

阶段二 wall-clock 约 **1–2小时**。E3失败时停止正式训练，先修数据、采样率、tokenizer或指标。

## 阶段四：核心实验

直接近邻已经存在：ICASSP 2023《More Speaking or More Speakers?》和Interspeech 2025的speaker count/duration/accent diversity研究均控制过说话人数与音频时长。因此A/B实验应作为**壮语受控复现和扩展**，不能单独写成“首次提出小时数—说话人数关系”。

- **A组固定5小时**：1/2/4/8名训练说话人；记录数据抽样seed和训练seed。
- **B组固定8名**：5/10/20小时；不能凭空构造固定8人100小时。
- **C组容量/预训练**：XLS-R-300M、XLS-R-1B、Whisper-small/medium；large-v3只做全量LoRA端点。
- **D组诊断**：已见/未见文本、录音域、说话人、长度和正字法分层；音系指标须先通过语言学核验。
- **瑶语验证**：身份、来源重叠和冲突复核后，再做target-only与迁移对照。

最小主文矩阵约 **30–60个训练run**。4张真正空闲L20、每个run 1–6小时，理论并行约 **8–24小时**；实际预留 **1–3天**。扩展到1B/medium/large和5 seeds后，预计 **3–7天**。

## 阶段五：结果、图和论文

| 任务 | 预计耗时 | 依赖 |
|---|---:|---|
| 结果解析、均值/标准差/bootstrap | 2–4小时 | 结果格式稳定 |
| 主结果表、人数/时长曲线、分层表 | 2–4小时 | 结果分析通过 |
| 训练曲线、规模曲线、speaker gap图、错误热图 | 2–5小时 | 数据表和指标稳定 |
| 相关工作精读和查新补充 | 3–8小时首轮，后续持续 | 专项检索和官方书目 |
| 数据/协议/方法章节 | 3–6小时 | split和环境冻结 |
| 结果/讨论/局限章节 | 4–8小时 | 真实结果和失败记录 |
| 引用核验、审计和模拟审稿 | 3–6小时 | 全文初稿 |

从第一组稳定结果到论文工作稿，预计 **1–3天**；从工作稿到可投稿稿取决于是否需要追加实验，通常再加 **2–7天**。

## 当前4小时调度

- **远程数据线**：瑶语身份/冲突、环境、异常复核和候选split；
- **文献线**：核心论文精读、speaker diversity专项检索、官方书目；
- **论文线**：数据/方法节骨架、表格模板、claim-evidence map；
- **本地线**：评分脚本单测、实验配置模板、run manifest模板。

只有同时满足以下条件才启动5小时基线：split冻结并通过泄漏检查；评分脚本人工样例全通过；极小集过拟合和checkpoint恢复通过；目标GPU归属明确；预测、参考、配置、日志和退出码有固定保存目录。

## 可以连续运行数小时的工作

适合持续运行：论文全文抽取和精读、公开全文下载重试、官方BibTeX核验、音频缓存、音频解码抽样、环境盘点和已通过门控的训练。都写阶段性文件和日志，可以中断后恢复。

不适合无门控连续运行：自动选择冲突转写、猜测瑶语身份、随机句级正式测试、占用未知GPU进程直接开大模型。
