# 实验方案 v0：Beyond WER 的低资源壮语 ASR

制定日期：2026-10-13。该方案基于当前已知条件（壮语语音—文字配对数据超过120小时，瑶语数据规模未确认）和项目文献综述。明天完成数据盘点后冻结数据切分、模型版本和训练预算。

## 一、拟定题目

中文：**小时数还是说话人数？低资源壮语 ASR 的说话人多样性、数据规模与音系可解释评测**

英文：**Hours or Speakers? Disentangling Speaker Diversity, Data Scale, and Phonological Errors in Low-Resource Zhuang ASR**

如果明天确认说话人数不足约8人，则退回保守题目：**超越 WER：面向低资源壮语 ASR 的说话人隔离、数据规模规律与音系可解释评测**。

## 二、研究问题与主张

### RQ1：小时数还是说话人数

在总训练小时数相同的情况下，增加说话人多样性是否比增加同一说话人的录音时长更能改善未见说话人的识别？在固定说话人数时，5、20、50、100及全部训练小时的收益曲线如何？

**H1：** 跨说话人测试下，小时数和说话人覆盖存在不同的边际收益；同一说话人的额外录音可能主要改善域内表现，随机句级切分会高估泛化能力。

### RQ2：WER/CER 与音系错误

WER/CER 是否掩盖了声母、韵母、音节和声调层面的差异？FER/TER 是否会改变模型排序或揭示传统指标看不到的瓶颈？

**H2：** 在声调和音节标签可靠时，音系指标能解释至少一部分词面错误；如果模型排序不改变，也报告这一评测边界，不强行宣称有效。

### RQ3：预训练模型的数据效率

Whisper-small、XLS-R-300M 或 wav2vec2-XLSR 等路线在不同训练小时数下的数据效率是否不同？

**H3：** 跨语言预训练路线在低小时数下优于从头训练，但优势受 tokenizer、语言覆盖和说话人划分影响。

## 三、数据协议

1. 以说话人为首要切分单位，目标为 train/dev/test = 80/10/10；若说话人数不足，改用原始长录音、文档或时间隔离，并在论文中明确限制。
2. 同一长录音切片不能跨集合；重复提示文本另做文本隔离分析，不能与普通测试混淆。
3. 固定 dev/test，构造两组训练子集：A 组固定总量约20h，比较 1/2/4/8/16 名说话人；B 组固定约8或10名说话人，比较 5/20/50/100/all 小时。每格保持每人时长尽量平衡，并做2–3个随机抽样种子。
4. 文本预处理在查看测试结果前冻结：Unicode NFC、空白、标点、数字和大小写规则写入脚本。
5. 并行保存保调原文、规范化文本和必要的去调版本。删除调号只能作为独立评分条件，不能为了提高分数临时处理。
6. 明天必须记录：语言变体、有效小时数、句数、说话人数、录音域、转写者、音节/音素/调号规则和数据许可。

## 四、模型和基线

### 必跑

1. **XLS-R-300M 或 wav2vec2-XLSR-300M + CTC**：跨语言编码器基线。
2. **Whisper-small + LoRA 或受控微调**：序列到序列基线。

### 条件允许时

3. **Conformer/CTC 从头训练**：用来区分预训练收益；若算力不足放到附录。
4. **MMS**：只有在官方 checkpoint 与具体壮语变体匹配时才加入，不能仅凭语言名称判断覆盖。

所有模型统一采样率、数据划分、early stopping 规则、主要训练预算和验证集。记录参数量、显存、训练时长和有效更新数。

## 五、指标

### 主指标

- 保调 CER；
- 原始 WER；
- 规范化 WER。

### 条件指标

只有在语言学映射可靠时才计算：

- 音节错误率；
- Feature Error Rate：声母、韵母、尾音、调类等特征分别统计；
- Tone Error Rate；
- 按说话人、调类、录音域的混淆矩阵。

每个音系指标必须记录标签来源、音节对齐规则、插入/删除处理和分母。若调号或音节边界不可靠，取消 TER，不制造声调标签。

统计上报告按说话人的宏平均、按句子的微平均，以及配对 bootstrap 95% 置信区间。多 seed 时报告均值和标准差，并比较模型排序的 Spearman 相关。

## 六、主表和图

1. **主结果表**：模型 × 全量数据，raw/norm CER/WER，若可行加入 FER/TER。
2. **说话人多样性表**：固定20h下 speaker 数量对 CER/WER 的影响。
3. **小时数曲线**：固定 speaker 数下 5/20/50/100/all 小时的 CER/WER/FER/TER。
4. **泛化差距图**：同 speaker 与 held-out speaker 的差异，以及随机句级切分的乐观偏差。
5. **音系错误图**：声母、韵母、尾音、调类混淆热图。
6. **误差案例表**：典型插入、删除、同音混淆、调类混淆和正字法差异。

## 七、执行顺序

### M0：数据和指标验收

- 生成说话人、录音、句子、时长清单；
- 检查重复音频、重复文本和跨集合泄漏；
- 冻结文本规范化规则；
- 用一个极小子集做过拟合测试；
- 对指标脚本做人工样例单元测试。

**停止门：** 小集合无法过拟合，或指标脚本无法稳定解析，先修数据和评测，不进入大规模训练。

### M1：快速基线

- 5小时壮语训练集；
- XLS-R-CTC 和 Whisper-small；
- 固定 dev/test；
- 每个模型先跑一个 seed。

目标是确认数据管线、显存、训练速度和指标方向。

### M2：小时数—说话人数正交实验

- 先跑固定20小时、不同 speaker 数的 A 组；
- 再跑固定8或10名 speaker、不同小时数的 B 组；
- 两个主模型，关键格至少2–3 seeds；
- 输出“每增加一倍小时数”和“每增加一倍 speaker 数”的相对变化及 speaker-bootstrap 置信区间。

### M3：稳健性和音系诊断

- 对 50/all 小时关键配置跑 3 seeds；
- raw vs normalized 文本评分；
- speaker、domain、音系类别分层；
- bootstrap 置信区间；
- 生成错误热图和案例。

### M4：可选瑶语迁移 pilot

只有明天确认瑶语有足够的具体变体、说话人和配对小时数后才执行：

- target-only 瑶语微调；
- 壮语预适配后瑶语微调；
- 直接多语言基线；
- 1h/5h/all 瑶语数据点。

若瑶语少于约5小时、只有单说话人或文字规则不清，M4 只作为趋势和失败模式，不写成双语主线。

## 八、暂不采用的主方法

暂不把“声调辅助任务、动态门控、F0 课程学习、音素边界增强”作为第一主线。这些方法已有 Bribri、SITA、T-SANDHI、Bantu 和粤语近邻。只有在完成基线、证明壮语的主要瓶颈确实是声调，并补齐直接近邻全文后，再设计轻量声调增强消融。

## 九、失败判据与改道

- speaker-disjoint 结果远差于随机切分：优先写数据泄漏和说话人记忆问题；
- FER/TER 标签不可靠：改为 phonologically informed 的音素/音节错误分析，取消 TER；
- WER/CER 与 FER/TER 排序完全一致：报告评测边界，把重点转为规模规律和错误解释；
- 单 seed 提升小于 bootstrap 不确定性：不宣称方法有效；
- 瑶语迁移没有稳定收益：保留为负结果或删除，不强行讲语言亲缘因果。
